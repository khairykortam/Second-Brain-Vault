# Chapter 1: You are your memory

We have a pretty poor memory for very familiar things - coins, for example. Because much of the details are irrelevant  - color, size, dimensions - when we are using money(for payment and money exchange), we tend to forget them. On the other hand, we typically remember people's faces. 

A student may not recall the exact content of a lecture per se. However, he may recall it in a general sense(called semantic memory). This type of memory is implicitly encoded, even without consciously recalling.

Emotions are not, surprisingly, dependent on our intention to remember events. Events alters either our thoughts, feelings, or behavior.

There have been multiple proposed theories of memory throughout history. Plato, for example, viewed memory as a clay tablet. Memory is impressioned(i.e encoded), and subsequently stored so that we can retrieve them. Memory was also compared with catching the right bird in a flying flock. However, contemporary scientists view memory of as a selective and interpretive process, rather than merely a passive storage of information.
